# Playbook: проверь проблемные

Пользователь помечает в UI ⚑ «проблемная» вакансию, у которой, по его мнению, неверный скоринг или данные.
Флаг снимает только пользователь; агент отмечает, что проверил, полем `flag_reviewed_at`.

1. Список: вакансии с `flagged: true` и пустым `flag_reviewed_at`
   (`grep -rl '^flagged: true' data/vacancies` → проверь `flag_reviewed_at`).
2. Для каждой: прочитай `notes` (там обычно причина), текст вакансии и поля скоринга. Перепроверь по `playbooks/scoring.md`:
   стоп-флаги, `company_country`, оценки, `resume_match`, `summary`. Если нужно — открой `real_url` (`npm run fetch-page`).
3. Исправь то, что неверно. Не уверен — не меняй, опиши сомнение в `score_reasoning`.
4. Допиши в `notes` строку `[агент YYYY-MM-DD] что проверено / что исправлено` (не затирая заметки пользователя),
   поставь `flag_reviewed_at: <сегодня>`. `flagged` не трогай.
5. `npm run score && npm run validate`.
6. Если ошибка системная (повторяется в нескольких вакансиях) — запись `[scoring]` в `data/insights.md` с предложением правки playbook/конфига.
7. Отчёт: сколько проверено, что исправлено, какие системные выводы.
