# Playbook: обновить заготовки резюме

Фраза: «обнови заготовки резюме [<трек>]». Пересобирает `profile/resumes/<трек>.md` из банка фактов, конфига треков
и рынка вакансий, чтобы заготовки проходили автоматические фильтры «в среднем по индустрии».
PDF (`tailor.md` §1) и резюме под вакансию (`tailor.md` §3) потом опираются на эти заготовки.

## Вход

- `profile/facts.md`, `profile/projects.md`, `config/resume-tracks.yaml`, `config/tech-dates.yaml`;
- рынок: `npm run insights` (свежий `data/runs/<дата>-insights.md`) — спрос трека, обязанности, написания навыков;
- журнал: `data/insights.md` — записи `[resume]`;
- `profile/questions.md` — ответы пользователя (сначала перенеси их в `facts.md`).

## Шаги

1. `npm run insights`. Если в отчёте «Поля v3 заполнены у N из M» с N заметно меньше M или обязанности не из словаря
   (каждая встречается по 1 разу) — скажи пользователю: рынок посчитан неточно, предложи `npm run pending -- --market`.
2. Для каждого трека из `resume-tracks.yaml`:
   - **Skills:** навыки из пула `facts.md`, которые встречаются в required/nice_to_have трека, — в порядке частоты,
     самым частым написанием («Как пишут навыки»). Навык рынка из «учил»/«само собой» — добавить.
     Навык рынка ≥ 10% вакансий трека, которого нет в фактах вовсе, — вопрос в `profile/questions.md`.
     Убрать навыки, которых нет ни в спросе трека, ни в профиле роли. 25–35 позиций.
   - **Experience:** места и должности — по `resume-tracks.yaml`; стек — подставить в плейсхолдеры;
     пункты — закрывают самые частые обязанности рынка трека, на JBS — самые частые; формула и лимиты — `tailor.md` §3 п. 4.
     Новый пункт по мотивам — сначала в `facts.md` с `~`.
   - **Summary** — топ-4 навыка спроса трека и главная обязанность.
   - **projects** — из `resume-tracks.yaml`; поправь, если рынок трека явно просит другое (и обнови yaml).
3. `npm run resume-check -- --tracks` — исправить все ✗. `npm run render-resume -- --all` — каждый PDF ≤ 2 страниц.
4. Переводы устарели (рендер предупредит) — обнови по `tailor.md` §2 или скажи пользователю.
5. Отчёт пользователю (по-русски): по трекам — что добавлено/убрано в Skills и почему (с долями рынка), какие пункты
   поменялись, новые `~` в `facts.md` (просить проверить цифры), новые вопросы в `questions.md`.
   Добавь запись `[resume]` в `data/insights.md`.

Заготовки — генерируемые: ручные правки пользователь делает в `facts.md` / `resume-tracks.yaml`.
Перед перезаписью копия старых заготовок — в `data/backups/resumes-<дата>/`.
