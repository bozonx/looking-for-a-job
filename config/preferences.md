# Предпочтения (обезличенные) → правила скоринга

Этот файл — человекочитаемое описание того, что важно. Числа живут в `weights.yaml`.

- **Главное — полная удалёнка** (`remote`, вес 3). Офис/гибрид допустим только в Буэнос-Айресе и Мар-дель-Плате; иначе стоп-фактор `office_outside_ar`.
- **Соответствие направлению** (`fit`, вес 4): vue / react / angular / fullstack / ai_engineer (Node.js-база; из других языков — Rust, Python, Go).
- **Легитимность** (`legitimacy`, вес 2): реальная компания, сайт, адекватное описание. < 30 → `scam`.
- **Язык** (`language`, вес 2): ru / en / es — ок; требование другого языка снижает оценку.
- **Регион** (`region`, вес 1): см. `regions.yaml`.
- **Стартап** (`startup`, вес 1) — плюс.
- **Корпорация как наниматель** (`corporate`, обратный вес 2) — минус: формальности, присутствие, документы.
- **Аутсорс/аутстаф** (`outsource`, обратный вес 0.5) — небольшой минус, но допустимо. Аутстаф на крупного клиента — приемлемо при удалёнке (`end_client_corporate`, обратный 0.5).
- EOR (Deel, Remote.com и т.п.) — допустимо.
- Стоп-факторы: `office_outside_ar`, `ru_corporate`, `inadequate`, `scam` (см. dev_docs/design.md §8.1).
