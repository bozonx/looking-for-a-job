# profile/ — персональные данные (вне git)

В git лежат только `*.example.md`. Чтобы заполнить: скопируйте пример без `.example`
(`about.example.md` → `about.md`) и впишите свои данные. Агент читает файлы без `.example`.

| Файл | Что внутри | Кто использует |
|---|---|---|
| `about.md` | контакты (шапка резюме), «Локация в резюме», языки, локация, гражданство, визы, зарплатные ожидания | скоринг (регион, визы), отклик |
| `answers.md` | накопленные ответы на типовые вопросы форм | отклик (этап 3) |
| `cover-letter.md` | пожелания к сопроводительным письмам | отклик (этап 3) |
| `resumes/<направление>.md` | «идеальное» резюме трека на английском без контактов и проектов: front matter (`title`, `projects`), Summary, Skills, Experience, Education | выбор `best_resume`, база для PDF и адаптации |
| `resumes/i18n/<направление>.<lang>.md` | переводы треков (ru, es), делает агент | PDF на других языках |
| `projects.md` | пул пет-проектов: темы, стек, описание en/ru/es | 0–2 в резюме по теме вакансии |
| `facts.md` | банк правдивых фактов: все пункты опыта, реальный стек, полный пул навыков | адаптация под вакансию подтягивает отсюда |
| `soft-skills.md` | soft skills с доказательствами | вплетаются в Summary/опыт, отдельной секцией не выводятся |
| `media/` | заготовленные видео-/аудио-визитки | отклик (этап 3) |
