# profile/ — персональные данные (вне git)

В git лежат только `*.example.md`. Чтобы заполнить: скопируйте пример без `.example`
(`about.example.md` → `about.md`) и впишите свои данные. Агент читает файлы без `.example`.

| Файл | Что внутри | Кто использует |
|---|---|---|
| `about.md` | контакты, локация, гражданство, визы, зарплатные ожидания | скоринг (регион, визы), отклик |
| `answers.md` | накопленные ответы на типовые вопросы форм | отклик (этап 3) |
| `cover-letter.md` | пожелания к сопроводительным письмам | отклик (этап 3) |
| `resumes/<направление>.md` | резюме под направление (vue, react, angular, fullstack, ai-engineer) | выбор `best_resume`, адаптация |
| `media/` | заготовленные видео-/аудио-визитки | отклик (этап 3) |
